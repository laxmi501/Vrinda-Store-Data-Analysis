# Vrinda-Store-Data-Analysis
Excel-based data analysis project for sales &amp; performance insights.
## 📁 Project Overview
This project focuses on analyzing Vrinda Store’s 2022 sales data using Excel to uncover business insights and customer purchasing trends.  
The aim is to help the business improve sales strategy, customer targeting, and channel performance.

---

## 🎯 Objectives
- Compare monthly sales and orders
- Identify the highest performing month
- Analyze customer purchasing behavior by gender and age group
- Evaluate order status distribution
- Identify top 5 revenue-generating states
- Determine the most profitable sales channel
- Analyze product category performance
- Build an interactive Excel dashboard

---

## 🛠️ Tools & Techniques Used
- **Microsoft Excel**
- Pivot Tables
- Pivot Charts
- Power Query (for cleaning)
- Slicers & Interactive Dashboard
- Data Modeling
- KPI Analysis

---

## 📊 Key Insights
- **Women purchased more than men** in 2022.
- **Adult age group (30–49)** contributed the highest number of orders.
- **Maharashtra, Karnataka, and Uttar Pradesh** were the top-performing states.
- **Amazon** generated the highest sales among all channels.
- **Clothing/Fashion** was the most purchased category.
- Sales peaked in **March and December.**
